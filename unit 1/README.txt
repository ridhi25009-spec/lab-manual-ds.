Social Network Explorer (SNE)

Features:
- Profile management using hashing
- Graph-based network (adjacency list)
- BFS for shortest path
- DFS for exploration
- Recommendation system based on common interests

How to Run:
python main.py

Complexity:
- Profile ops: O(1)
- Graph ops: O(1)
- BFS/DFS: O(V+E)
- Recommendation: O(N log N)
